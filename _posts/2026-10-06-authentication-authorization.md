> **미리보기 예시** · 실제 개인 학습 기록을 대신하지 않는 샘플 글입니다.

## 인증: 누구인가?

인증은 사용자가 주장하는 신원을 확인하는 과정입니다. 비밀번호나 보안 키로 계정에 로그인하는 상황이 대표적입니다.

## 인가: 무엇을 할 수 있는가?

인가는 확인된 사용자에게 어떤 작업을 허용할지 판단하는 과정입니다. 로그인했더라도 다른 사람의 비공개 글을 수정할 수 있어서는 안 됩니다.

| 상황             | 확인할 내용                                |
| ---------------- | ------------------------------------------ |
| 계정 로그인      | 올바른 인증 수단을 제시했는가?             |
| 내 글 수정       | 요청한 사용자가 글을 수정할 권한이 있는가? |
| 관리 페이지 열기 | 필요한 관리자 권한이 있는가?               |

## 기억할 점

화면에서 버튼을 숨기는 것만으로는 권한 검사가 끝나지 않습니다. 서버가 요청을 처리할 때에도 해당 작업의 권한을 확인해야 합니다.
