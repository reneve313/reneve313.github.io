> **미리보기 예시** · 실제 진행 프로젝트가 아닌 화면 확인용 샘플입니다.

## 프로젝트의 질문

웹 요청이 들어왔을 때 인증과 접근 권한은 어디에서 확인해야 할까요? 작은 로컬 실습 앱을 만든다는 가정으로 관찰할 항목을 정리합니다.

## 실습의 범위

1. 로컬에서만 실행하는 간단한 앱을 준비합니다.
2. 일반 사용자와 관리자의 역할을 나눕니다.
3. 각 역할이 접근할 수 있는 화면과 요청을 표로 정리합니다.

## 다음 기록

테스트할 요청과 기대하는 응답을 정리하고, 결과를 비교하는 방식으로 이어갈 예정입니다.
