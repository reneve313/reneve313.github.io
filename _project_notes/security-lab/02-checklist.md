> **미리보기 예시** · 아래는 테스트 결과가 아닌 실습 계획의 예시입니다.

## 테스트 항목

| 요청 상황                                   | 기대하는 동작  |
| ------------------------------------------- | -------------- |
| 로그인하지 않은 사용자의 비공개 페이지 요청 | 인증 필요 안내 |
| 일반 사용자의 관리자 페이지 요청            | 접근 거부      |
| 작성자의 자기 글 수정 요청                  | 수정 허용      |

## 기록할 내용

각 항목에서 요청, 기대 결과, 실제 결과를 함께 남기면 문제가 생긴 지점을 되짚어 보기 쉽습니다. 수정 후에는 이전 항목을 다시 확인하는 과정도 기록합니다.
